# games

Coleção de jogos web simples.

## Jogos
- `jogo-cobrinha/` — Snake retro em HTML/CSS/JS (setas, R reinicia, V velocidade 1x/2x/3x, T tela cheia, ENTER/ESPAÇO pausa, atravessa parede)
- `jogo-xadrez/` — Xadrez completo (2 jogadores locais ou bot com 5 níveis, relógio 30 min cada; roque, en passant, promoção, xeque/xeque-mate, afogamento, 50 lances, tripla repetição, material insuficiente)
- `jogo-damas/` — Damas brasileiras (2 jogadores locais ou bot com 5 níveis, relógio 30 min cada; captura obrigatória com maioria, dama voadora, 40 lances sem progresso, tripla repetição)

## Rodar
- Abra `jogo-cobrinha/index.html` no navegador.
- Abra `jogo-xadrez/index.html` no navegador.
- Abra `jogo-damas/index.html` no navegador.
